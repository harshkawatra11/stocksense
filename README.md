# StockSense

An autonomous research and paper-trading system for the National Stock Exchange of India.
It keeps NSE data current, builds features, trains and validates models (LightGBM, a GRU network, Kronos),
paper-trades the result all day without supervision, explains every pick, and learns every night.

Paper trading only. The full plan, conventions and status are in [docs/PLAN.md](docs/PLAN.md).
