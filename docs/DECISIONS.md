## Phase 3

- T3.1 (2026-11-11): nodes are symbols (same symbol = same sid, so a symbol never maps to two sids and CA/symbol joins can use the symbol alone; `valid_from/valid_to` are informational). Edge B additionally skips a candidate B that already has an incoming official edge (a node may have one in-edge). Official edges are accepted closest-date-first, auto edges by `(last_date, symbol)`; a union-find rejects cycles. "Sessions between" is the difference of 0-based indices in the distinct `bhavcopy_eq` date list (all series). `sid_merges.csv` is appended to across runs; `rename_autodetect.csv` is rewritten each run. If an earlier auto-detected edge disappears later (a second candidate shows up), the two symbols keep their (shared) existing sid; sids are never re-numbered.
- T3.2 (2026-11-11): `compute_gap_factors(rows, ca)` takes `rows` = (sid, date, session_idx, open, close, prev_close) and `ca` with `sid` already joined (an optional `face_fallback` column feeds rights), and returns a SPARSE audit frame (only rows needing a factor, plus `ca_ignored` rows dated at the ex-date; extra columns `ca_types`, `note`); `build_daily_panel` joins it to the full rows (gap_factor 1.0, gap_src '' elsewhere). A sid's first row never receives a factor. Two table events picking the same row keep the better fit. Step 4 ("first row after, within 5 sessions") takes the first row at/after the ex-date only, not the first row with a big move.
- T3.2 (2026-11-11): the synthetic S25 rights row has null ratio/price columns (`unparsed`), so step 3 reads `ratio_num/den/rights_price` and, when null, parses `subject_raw` (`1:4`, `@ Premium Rs 40` -> issue price = face + premium; face = `face_before`, else the latest `listed_equities.face_value`, else 10; `@ Rs 50` is taken as the issue price). Row = the first row at/after the ex-date within 5 sessions; applied only if issue price < base. The planted S25 price does NOT drop on the rights date, so the theoretical ex-rights factor over-corrects that one day: S25 is the only stock excluded from the 2% compounded-return test (measured mismatch +7.1%, asserted > 2% so the exclusion is exact). S16 demerger passes (mismatch 0.58%: the implied_event convention drops that day's overnight gap).
- T3.2 (2026-11-11): dividends are attached to the first session on/after the ex-date (all CA rows with `dividend_amount`, any type) and dropped if that sid has no row on that session. `industry` is mapped by sid (latest `sectors` snapshot of any symbol of the company), so renamed symbols share it; `UNKNOWN` if no sector row. Returns are NULL (not -100%) where open or close is non-positive. Memory plan for 8.4M rows: one eager frame, written one year at a time (delivery read per year).
- T3.3 (2026-11-11): `panel/universe/` holds one row per ELIGIBLE (sid, date) only (`turnover_rank` is never null); a sid-date not present is not a member of anything. Windows are session-based via integer-indexed rolling functions (`60i`, `20i` over the global session index of `bhavcopy_eq` dates): "traded in >= 57 of the last 60 sessions" counts that sid's rows in the window ending at t, "not flag_stale in the last 20 sessions" looks at the same 20-session window including t, and `med_turn_60` is the median of the last 60 ROWS (min 1). ETF test is per sid: any of its symbols in `etf_list`, or a symbol / the latest security-master name matching `etf_name_regex` (the panel has no per-row name). Ranks are ordinal (ties broken by sid). The hysteresis loop carries the previous processed session's member arrays; a session with no eligible rows resets nothing because it is simply not visited. `in_fno` on/after 2024-07-08: symbol has an `STF` row in `fo_bhavcopy` on that date; a session with no F&O file at all takes the last F&O date's set if at most 5 sessions back, else False (a stock missing from an existing day's file is False); before it: `turnover_rank <= 150`.
